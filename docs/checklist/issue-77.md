自动验证：`cargo test -p tml-core -p tml-app`（core `connections`：IPv4 / IPv6 表项解析与地址、端口字节序，截断数据只取完整表项，TCP 状态映射，表变大时重试与放弃，错误带协议与错误码；真实系统调用冒烟：自己开 `TcpListener` 并连上，按本进程 PID 找到监听端口与已建立连接。app `connections_page`：搜索进程名 / PID / 协议 / 地址 / 端口 / 状态，六列双向排序且稳定键打破平局，稳定键不含状态，进程名解析与“—”，PID 0 / 快照里没有的进程不可“转到进程”，Ctrl+1…6 页序，连接页与服务页的工具栏在 760–1400 宽度都放得下）。

## 人工验收（等回到电脑前）

- [ ] 1. 排序：依次点六个表头，再点一次反向；升降箭头与顺序符合预期（状态列升序时 UDP 的空状态在前）。
- [ ] 2. 搜索：Ctrl+5 进入连接页，Ctrl+F 聚焦本页搜索框，输入端口号（如 `:443`）、进程名、`监听`，列表随之过滤；Esc 清空并回到列表；F5 立即刷新。
- [ ] 3. 刷新稳定：选中一条已建立的连接，等待若干秒，选中项不跳到别的行、滚动位置不回到顶部。
- [ ] 4. 右键菜单：右键一行弹出“转到进程”，切到进程页并选中对应 PID；对 PID 0（TIME_WAIT 等）或已退出进程的行，菜单项与底栏按钮置灰。
- [ ] 5. 窄窗口：窗口缩到最窄（约 760），侧边栏收成图标，“连接”图标（双向箭头）可点，列表各列不重叠，地址省略号显示。
- [ ] 6. 浅色主题：设置里切到浅色，连接页表头、选中行、底栏按钮颜色正常。
- [ ] 7. 与资源监视器“网络 → 侦听端口 / TCP 连接”对照几项，进程名、端口一致。
- [ ] 8. 设置页底部“键盘快捷键”写着 Ctrl+1 … 6，依次为进程、性能、启动项、服务、连接、设置。
