# MVP 人工验收清单（2026-10-27）

运行：`target/release/TaskManagerLite.exe`（`cargo build -p tml-app --release` 构建）。日志在 exe 同目录的 `logs/`。

已自动验收（无需人工）：进程采样与进程树单元/冒烟测试、真实结束进程树、启动耗时与常驻开销测量、8 张离屏截图（`media/2026-10-27/`，由 `pwsh scripts/screenshots.ps1` 生成）。

- [x] **1. 冷启动体感**
  - 操作：双击 exe 启动，与原生任务管理器（Ctrl+Shift+Esc）对比。
  - 预期：窗口几乎立即出现，进程列表不到半秒就有数据。
  - 反馈：通过（2026-10-27）

- [x] **2. 排序与选中**
  - 操作：依次点击列头 名称/PID/CPU/内存/磁盘，再点一次同列；用上下键、PageUp/PageDown 移动选中行。
  - 预期：首次点数值列降序、名称/PID 升序；再点反转，列头箭头随之变化；刷新数据时选中行保持不跳。
  - 反馈：通过（2026-10-27）

- [x] **3. 搜索（Ctrl+F）**
  - 操作：按 Ctrl+F，输入 `svchost`；再输入不存在的名字。
  - 预期：焦点进入搜索框，列表即时过滤；无匹配时显示“没有匹配的进程”。
  - 反馈：通过（2026-10-27）

- [x] **4. 树形模式与展开折叠**
  - 操作：勾选“树形”，点击带箭头的节点折叠/展开；树形模式下搜索。
  - 预期：子进程缩进显示在父进程下；折叠后子项隐藏；搜索时命中项的祖先保留并自动展开；父进程已退出的子进程出现在根层级。
  - 反馈：通过（2026-10-27）

- [x] **5. 结束进程（右键菜单 / Delete / 按钮）**
  - 操作：打开记事本，选中 notepad.exe，分别用右键“结束进程”、Delete 键、顶部“结束进程”按钮结束。
  - 预期：普通进程直接结束，无确认；状态栏提示成功，列表中该行随即消失。
  - 反馈：通过（2026-10-27）

- [x] **6. 结束进程树确认**
  - 操作：在 cmd 里运行 `ping -t 127.0.0.1`，右键 cmd.exe 选“结束进程树”；再试一次并按 Esc 取消。
  - 预期：弹出确认框并显示后代数量；确认后 cmd 与 ping 都结束；Esc 关闭对话框且不结束任何进程。
  - 反馈：通过（2026-10-27）

- [x] **7. 关键进程保护**
  - 操作：选中 explorer.exe（或 TaskManagerLite 自身）按 Delete，在确认框点取消。
  - 预期：行上有“关键”标签；结束前出现警告确认；取消后什么也不发生。（不要真的确认结束 csrss 等系统进程。）
  - 反馈：通过（2026-10-27）

- [x] **8. 提权重启**
  - 操作：普通权限下尝试结束一个服务进程（如 svchost），然后点“以管理员身份重启”。
  - 预期：状态栏提示权限不足；点按钮后弹出 UAC，同意则以管理员身份重新打开（按钮消失），拒绝则原窗口保持不变。
  - 反馈：通过（2026-10-27）

- [x] **9. 采样间隔**
  - 操作：在下拉框中依次切换 0.5 秒 / 1 秒 / 2 秒 / 暂停。
  - 预期：刷新节奏随之变化；暂停时数值和曲线冻结，恢复后曲线在暂停处断开再继续。
  - 反馈：通过（2026-10-27）

- [x] **10. 最小化暂停**
  - 操作：切到“性能”页，最小化窗口约 10 秒后还原。
  - 预期：最小化期间不采样（可在资源监视器看到本程序 CPU 为 0）；还原后曲线在最小化区间留出断口。
  - 反馈：通过（2026-10-27）

- [x] **11. 性能页与窗口缩放**
  - 操作：在性能页逐个点击 CPU/内存/磁盘/网络卡片，拖动窗口改变大小。
  - 预期：大图切换到对应资源、颜色一致；曲线随窗口尺寸重新铺满，不变形。
  - 反馈：通过（2026-10-27）

- [x] **12. 浅色主题跟随系统**
  - 操作：Windows 设置 → 个性化 → 颜色，切换浅色/深色应用模式。
  - 预期：界面配色随系统切换，文字与曲线在两种主题下都清晰可读。
  - 反馈：通过（2026-10-27）
