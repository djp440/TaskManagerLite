# Issue #71 键盘快捷键验收

自动验证：`cargo test -p tml-core -p tml-app`（含 `Service::matches`、`Entry::matches` 搜索单测，五页面工具栏布局）；`pwsh scripts/test-shortcuts.ps1` 用 SendInput 发真实按键，读日志核对 Ctrl+1…5 切页、Ctrl+F 聚焦三页搜索框、搜索框内输入数字不切页、搜索框内 Ctrl+数字仍切页且不写入数字、过滤与 Esc 清空、F5 各页刷新入口、迷你窗口不响应新快捷键，并把各页截图存到临时目录。

以下几项无法用日志或脚本完全替代，需要人工看一眼（4 级）：

- [ ] 1. 搜索框焦点与侧边栏高亮的视觉效果（4 级）
  - 操作：依次按 Ctrl+1…5，再在进程页、启动项页、服务页各按一次 Ctrl+F。
  - 预期：侧边栏高亮随页面同步（进程、性能、启动项、服务、设置）；Ctrl+F 后搜索框出现焦点下划线、已有文字被选中；输入后列表立即过滤；按 Esc 清空并恢复全部行，焦点离开搜索框。
- [ ] 2. F5 刷新的实际效果（4 级）
  - 操作：把刷新间隔设为“暂停”，在进程页或性能页按 F5；在启动项页、服务页用另一程序修改启动项或启停某服务后按 F5。
  - 预期：暂停状态下 F5 仍补采一次（进程数、CPU 读数更新一次）；启动项页、服务页的列表同步外部修改。（脚本只能验证 F5 触发了刷新入口，无法直接读到补采后的界面数值。）
- [ ] 3. 设置页“键盘快捷键”说明（4 级）
  - 操作：打开设置页，滚动到底部。
  - 预期：七行快捷键说明文字完整、键帽对齐，深浅色下都清晰；窗口窄到 760 时不被裁切。
- [ ] 4. 中文输入法下的快捷键（4 级）
  - 操作：切到中文输入法（拼音），在搜索框里输入拼音并按数字键选词；再按 Ctrl+数字、Ctrl+F。
  - 预期：数字选词正常，不会误切页；Ctrl+数字、Ctrl+F 行为与英文输入法一致（脚本只在当前输入法下验证）。
