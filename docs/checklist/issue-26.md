# Issue #26 服务页验收

自动验证：枚举结果解析、状态与启动类型映射、svchost 组名提取、配置缓存（每个服务只读一次、消失后清出）、各列升降序排序、非法提权参数拒绝、真实服务只读枚举；五页面在 760–1600 像素与两种权限状态下的工具栏布局（`cargo test -p tml-core -p tml-app`）。`pwsh scripts/test-services.ps1`（普通权限）核对服务数量与 `Get-Service` 一致、普通权限点击“启动”显示拒绝原因且不崩溃、“转到进程”选中服务所在 PID。

- [x] 1. 与原生任务管理器核对（4 级）
  - 操作：打开本程序“服务”页和原生任务管理器“服务”页，抽查若干服务的名称、PID、状态、组；悬停某行约 0.5 秒。
  - 预期：服务与状态一致；悬停显示显示名称和描述；六列表头可升降序排序；切到其他页时不再刷新（可在设置为 0.5 秒时观察 CPU），回到服务页状态随采样间隔更新。
- [x] 2. 提权启停（4 级）
  - 操作：普通权限启动本程序，选一个可安全测试、当前已停止的手动服务（例如“Windows 错误报告服务”或自建测试服务），点击带盾牌的“启动”：先在 UAC 中取消，再重试并确认；随后对同一服务点“重启”“停止”并确认 UAC。测试后恢复原状。也可用“以管理员身份重启”后直接操作（此时按钮不显示盾牌，也不弹 UAC）。
  - 预期：底栏先显示“正在启动服务…（需要管理员权限，请在 UAC 对话框中确认）”；取消时显示“无法启动服务“…”：操作已被用户取消”，窗口保持响应；确认后显示“已启动服务…”，状态和 PID 随即更新；停止有依赖服务正在运行的服务时显示系统给出的失败原因。
- [x] 3. 转到进程（4 级）
  - 操作：选中一个正在运行的服务，点击“转到进程”或双击该行；分别在平铺、树形（父节点折叠）、分组视图和有搜索词时各试一次。
  - 预期：切到进程页并选中、滚动到该 PID 所在的进程行（必要时展开祖先、清空不匹配的搜索词）。

验收结果：2026-10-29 用户确认 3 项人工验收全部通过。
