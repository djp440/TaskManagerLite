# Issue #67 挂起与恢复进程：验收

自动验证：`cargo test -p tml-core -p tml-app`（`procctl`：对自己启动的子进程真实挂起 / 恢复并通过采样器回读“已挂起”、挂起计数叠加后恢复次数要对应、PID 0 / 4 / 本程序拒绝、已退出进程与创建时间不符为“已退出”、权限探测 `ControlState::suspend`、`still_suspended`；`nt`：线程等待原因 → suspended 的判定（线程数 0、部分线程挂起不算）；`controller::suspend`：挂起 / 恢复目标 `suspend_targets`（已挂起不重复挂起、应用行 = 应用及全部后代、受保护进程排除）、菜单置灰与原因 `suspend_menu`、确认判断 `suspend_needs_confirm`、退出前提示判断 `exit_decision`（只弹一次、无本程序挂起的进程直接退出、测试模式不拦截）、状态列文字）；`pwsh scripts/test-suspend.ps1`（`--menu-action suspend|resume|suspend-ask|exit-prompt|exit-prompt-twice|exit-noprompt:<pid>[:group]` 钩子：用 `Process.Threads[].WaitReason` 回读真实挂起 / 恢复、重复挂起被拒绝且恢复一次即可、PID 4 被拒绝、关键进程 explorer.exe 先弹确认且未确认不执行、应用行作用于全部后代并先确认、退出前提示的弹出 / 取消 / 只弹一次 / 直接退出）。

设计要点（验收时对照）：

- “状态”列显示“已挂起”：来自采样里每个线程的等待原因（全部是 Suspended 才算），不额外打开进程；外部（原生任务管理器、资源监视器）挂起的进程同样显示。
- 挂起是计数式的：已挂起的进程“挂起”置灰、未挂起的“恢复”置灰，所以恢复一次一定生效。
- 关键进程（GLOSSARY“关键进程”）或一次作用于多个进程（应用行 = 应用及其全部后代）挂起前先弹确认框；“恢复”不需要确认。PID 0 / 4 与本程序自身置灰。没有权限（如受保护进程、其他用户的进程）置灰并写明“没有权限”。
- 退出（关闭按钮、托盘“退出”、迷你窗口的退出）时不自动恢复被挂起的进程；若本程序在本次运行中挂起、现在仍存在且仍处于挂起的进程还在，退出前弹一次提示（“仍然退出 / 取消”）。隐藏到托盘、最小化不算退出；外部挂起的进程不提示。

以下只留下自动测试覆盖不到的观感与第三方程序行为（4 级，等回到电脑前）：

- [ ] 1. 记事本挂起后真实无法输入（4 级）
  - 操作：打开记事本，在本程序进程页右键它选“挂起”，回到记事本尝试输入、移动窗口；再回到本程序右键“恢复”。
  - 预期：挂起后“状态”列显示“已挂起”（下一次采样内更新），记事本窗口无响应（标题栏可能变“未响应”）、输入没有反应；恢复后状态变回“正在运行”，之前输入的字符出现，窗口恢复正常。
  - 用户反馈：

- [ ] 2. 右键菜单的置灰与提示（4 级）
  - 操作：分别右键已挂起的进程、未挂起的进程、System / 系统空闲进程、本程序自身、另一个用户或受保护的进程（如 csrss.exe、MsMpEng.exe）。
  - 预期：已挂起的进程“挂起”置灰、标题写明“已挂起”，“恢复”可点；未挂起的进程“恢复”置灰、标题写明“未挂起”；System / 本程序自身两项都置灰并写明不可操作；没有权限的进程两项置灰并写明“没有权限”。
  - 用户反馈：

- [ ] 3. 挂起关键进程的二次确认弹窗观感（4 级）
  - 操作：右键 explorer.exe（或分组视图里含它的应用行）选“挂起”。
  - 预期：弹出确认框，标题与正文明确提示“关键进程，挂起可能让系统失去响应”，按钮为“挂起 / 取消”；点取消什么都不发生，点挂起后桌面任务栏停止响应，再回到本程序窗口右键“恢复”能恢复（本程序窗口不受影响；操作前先把本程序窗口放在不被任务栏遮挡的位置）。
  - 用户反馈：

- [ ] 4. 应用行批量挂起的确认（4 级）
  - 操作：分组视图里右键一个有多个进程的应用（如浏览器、Office 应用）选“挂起”。
  - 预期：弹确认框，写明将挂起的进程个数；确认后该应用的全部进程“状态”都变为“已挂起”，应用行的“恢复”可一次恢复全部。
  - 用户反馈：

- [ ] 5. 退出前提示弹窗观感（4 级）
  - 操作：挂起记事本后点窗口关闭按钮（以及托盘“退出”、迷你模式的退出）；设置里开启“关闭时最小化到托盘”后再点关闭按钮；再把记事本恢复后点关闭按钮。
  - 预期：关闭 / 退出时弹提示，说明“退出后这些进程仍保持挂起，可再次打开本程序恢复”，选“仍然退出”后程序退出且记事本仍是挂起（重新打开本程序能看到“已挂起”并恢复）；选“取消”回到窗口；开启托盘后点关闭按钮只是隐藏到托盘不提示；恢复后退出不再提示；最小化不提示。
  - 用户反馈：

- [ ] 6. 与原生任务管理器互通（4 级）

  - 预期：两边都能看到“已挂起”状态；外部挂起的进程在本程序退出时不触发提示。
