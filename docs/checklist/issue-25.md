# Issue #25 启动项页验收

自动验证：隔离注册表键的枚举、启用/禁用往返与原始命令保留；真实六类来源只读枚举；非法提权参数拒绝；四页面在 760–1600 像素与两种权限状态下的工具栏布局。

- [ ] 1. 与系统列表核对（4 级）
  - 操作：打开本程序“启动项”和原生任务管理器“启动应用”，核对 Run（HKCU/HKLM、32 位）及当前用户/所有用户启动文件夹中的项目。外部修改后点击列表项或表头，或切出再进入本页。
  - 预期：对应项目及启用状态一致；每项名称前显示程序图标（与原生任务管理器图标一致，解析不到程序时为通用程序图标）；名称、发布者、来源可见，悬停项目约 0.5 秒后显示完整命令行，浮层底色在深浅色主题下都与页面明显区分，四列表头可升降序排序，列表行高与进程页一致。此轮不包含计划任务和打包应用专用 StartupTask 来源。
- [ ] 2. 状态双向互通（4 级）
  - 操作：选一个可安全测试的当前用户启动项，在本程序禁用，然后重新打开原生任务管理器核对；在系统中重新启用，再点击本程序列表项触发刷新。测试后恢复原状。
  - 预期：两边状态一致；Run 原始值或启动文件夹文件始终保留。
- [ ] 3. 系统级项目与取消提权（4 级）
  - 操作：普通权限启动本程序，选 HKLM 或所有用户启动文件夹项目，点击右下角内嵌盾牌的启用/禁用；先取消 UAC，再用一个可安全测试的项目确认 UAC。测试后恢复原状。
  - 预期：取消时显示失败原因并保留实际状态；确认后修改成功，窗口保持响应，状态以重新读取的结果为准。
