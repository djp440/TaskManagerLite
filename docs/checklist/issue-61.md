# Issue #61 左侧边栏导航验收

自动验证：五个页面 × 三种状态（未提权、已提权、侧边栏折叠）在 760–1600 像素下的工具栏布局，包括侧边栏宽度随窗口宽度与折叠偏好变化（`cargo test -p tml-app toolbar_fits`）；设置字段 `sidebar_collapsed` 的读写与容错（`cargo test -p tml-app settings`）；截图模式里模拟点击侧边栏项切换页面、折叠与展开（`pwsh scripts/screenshots.ps1`）。

- [x] 1. 侧边栏外观与交互（4 级）
  - 操作：以默认窗口大小启动；依次点“进程 / 性能 / 启动项 / 服务”和底部的“设置”；在设置页再点一次“设置”；悬停各项。
  - 预期：顶栏不再有页面标签和品牌字样；当前页的图标与文字高亮，左侧有强调色竖条；再点“设置”回到进入设置前的页面；悬停有底色。深色与浅色下都清晰。
- [x] 2. 折叠与窄窗口（4 级）
  - 操作：点侧边栏顶部的菜单按钮折叠，再展开；把窗口拖窄到 900 以下再拉宽；折叠状态下悬停图标；折叠后退出并重新启动。
  - 预期：折叠后只剩图标，悬停约 0.5 秒出现文字提示；窗口宽度小于 900 时不论是否折叠都只有图标，且菜单按钮隐藏；重新启动后折叠状态保持（`settings.json` 的 `sidebar_collapsed`）。
- [x] 3. 工具栏不被挤出（4 级）
  - 操作：把窗口拖到最窄（760），在进程页和性能页查看工具栏；以普通权限与管理员权限各看一次。
  - 预期：搜索框、视图切换、刷新间隔、结束进程、置顶、提权按钮都完整可见，最窄时提权按钮收成盾牌图标；置顶按钮不再被收起。
- [x] 4. 其他入口不受影响（4 级）
  - 操作：Ctrl+F 搜索、Ctrl+M 进入迷你模式再双击回来、最小化到托盘（设置里开启）后唤起。
  - 预期：Ctrl+F 回到进程页并聚焦搜索框；回到完整模式后页面与侧边栏状态不变。

验收结果：2026-10-30 用户确认 4 项人工验收全部通过（含折叠/展开过渡动画）。
