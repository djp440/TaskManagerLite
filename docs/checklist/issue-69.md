# Issue #69 运行新任务验收

自动验证：`cargo test -p tml-core -p tml-app`（含命令拆分 `parse_command_with`、环境变量展开、`run_task` 对空输入与不存在程序的返回、设置里 `run_history` 的容错/去重/限长往返、错误文案、文件过滤串）；`pwsh scripts/test-run-task.ps1` 用 SendInput 发真实按键，读日志与设置文件核对：Ctrl+N 打开对话框（进程页、性能页）、已打开时再按不会开第二个、空输入回车无动作、不存在的程序回车显示失败（错误码 2）且对话框不关闭、输入 `notepad` 回车启动记事本并关闭对话框、历史写入设置文件并在再次打开时可见、旧版设置文件（没有 `run_history`）正常启动、“浏览…”打开系统文件选择对话框并可取消；脚本只清理自己启动的记事本与测试实例。

以下几项会弹 UAC、操作默认浏览器或影响桌面，脚本不覆盖，需要人工看一眼（4 级）：

- [ ] 1. 以管理员权限运行（4 级）
  - 操作：Ctrl+N（或点侧边栏底部“运行新任务”），输入 `cmd`，勾选“以管理员权限创建此任务”，回车。
  - 预期：弹出 UAC 确认；允许后以管理员身份打开命令提示符（标题带“管理员”），对话框关闭，历史里多一条 `cmd`。
- [ ] 2. UAC 里点“否”（4 级）
  - 操作：同上，但在 UAC 对话框点“否”。
  - 预期：运行对话框保持打开，输入框下方用红字提示“已取消：没有在 UAC 对话框中允许以管理员权限运行”，程序不崩溃；去掉勾选再回车可以正常启动。
- [ ] 3. 网址用默认浏览器打开（4 级）
  - 操作：输入 `https://www.bing.com` 回车。
  - 预期：默认浏览器打开该网址，对话框关闭。
- [ ] 4. 用 `explorer` 重启资源管理器（4 级，会闪一下桌面，**先保存手头工作**）
  - 操作：在本程序的进程页结束 `explorer.exe`（关键进程，按提示确认；桌面与任务栏会消失），然后 Ctrl+N，输入 `explorer` 回车。
  - 预期：桌面与任务栏恢复；对话框关闭。说明：资源管理器仍在运行时输入 `explorer` 只会再打开一个“此电脑”窗口，这与系统“运行”对话框一致，不是失败。
- [ ] 5. 浏览…选择文件（4 级）
  - 操作：Ctrl+N，点“浏览…”，选 `C:\Windows\System32\notepad.exe`（或任意含空格路径的程序），确定。
  - 预期：输入框填入完整路径（路径含空格时自动加引号）；点“确定”启动成功。
- [ ] 6. 命令拆分的真实效果（4 级）
  - 操作：依次输入（每次回车后关掉打开的程序）：`notepad C:\Windows\win.ini`；`"C:\Windows\System32\notepad.exe" C:\Windows\win.ini`；`%windir%\notepad.exe`；`C:\Windows`（打开文件夹）；`C:\Program Files\Windows NT\Accessories\wordpad.exe`（未加引号的含空格路径，若本机存在）。
  - 预期：都能打开对应的程序、文件或文件夹，没有错误提示。
- [ ] 7. 历史记录的使用与上限（4 级）
  - 操作：成功运行 11 个不同的命令后再打开对话框，点“最近使用”里的一条。
  - 预期：列表最新在前、最多 10 条（超出时可滚动看到全部 10 条）、重复运行同一条只出现一次并移到最前；点击某条后它填入输入框并保持焦点，可直接回车。
- [ ] 8. 对话框的外观与键盘操作（4 级）
  - 操作：在浅色、深色主题下打开对话框；窗口缩到最小（760×480）再打开；用 Tab 在输入框、浏览、复选框、取消、确定之间切换；回车确认、Esc 取消；迷你窗口里按 Ctrl+N。
  - 预期：与“结束进程树”确认框风格一致，文字不被裁切，焦点可见；Esc 关闭后焦点回到列表（可继续用方向键选进程）；迷你窗口不响应 Ctrl+N。
- [ ] 9. 中文输入法下的回车（4 级）
  - 操作：切到中文输入法，在输入框里键入拼音，按回车。
  - 预期：第一下回车是输入法上屏（输入的字母原样留在输入框），第二下才提交；这是输入法的正常行为，对话框本身不应出现重复启动。
