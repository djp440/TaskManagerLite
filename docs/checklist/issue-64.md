# issue #64 进程列表 GPU 占用列验收

自动化已覆盖：聚合/合计/排序单测、`process_gpu_probe` 与独立 PDH 聚合的数值核对。以下需要人工对照原生任务管理器。

- [ ] 1. 【4 级】显示 GPU 列：在进程页表头右键（或列选择菜单）勾选“GPU”。预期列出现在最右侧，右对齐；刚勾选后 1–2 秒内出现数值，不是一直“—”。取消勾选后列消失，再次勾选仍能快速出值。
- [ ] 2. 【4 级】与原生任务管理器对照：运行 GPU 负载（浏览器播放视频、游戏或 `dxdiag` 的“DirectX 工具”），同时打开原生任务管理器“进程”页并显示“GPU”列。预期同一进程的数值大体一致（采样时刻不同允许波动几个百分点）；无负载进程本程序显示 0%，不是“—”。
- [ ] 3. 【4 级】分组视图合计：切到分组视图，找一个有多个子进程的应用（如 Edge、Chrome），播放视频。预期折叠的应用行 GPU 为自身加全部后代的合计（可能大于任何单个子进程，不超过 100%），展开后子进程行显示各自的值；原生任务管理器应用行数值应相近。
- [ ] 4. 【4 级】排序与持久化：点击 GPU 表头，预期按占用降序（再点升序），无读数的进程排在最小一端；关闭并重新打开程序，GPU 列、宽度与排序仍保留，且启动后很快有值。
- [ ] 5. 【4 级】无 GPU 环境（可选，虚拟机）：在没有 GPU 的机器或虚拟机里显示 GPU 列。预期整列显示“—”，程序不报错。
