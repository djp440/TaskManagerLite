# Issue #82 导出为 CSV 与复制所选行：验收

自动验证：`cargo test -p tml-core -p tml-app`（CSV 编码的转义/BOM/CRLF/往返、`tab_line`、进程表格的列与层级、折叠节点仍导出、性能快照结构、敏感列判定、保存对话框缓冲区转换）；`pwsh scripts/test-export-csv.ps1`（需交互式桌面，运行期间不要动键盘鼠标）：用 `--export-csv` 钩子核对 BOM、CRLF、表头与界面列一致、名称排序、含逗号/引号的命令行经 `Import-Csv` 还原一致、树形与分组视图的“层级”“分组”列、性能快照的表头与 60 秒窗口内的曲线、写文件失败（错误码 3）；`--menu-action copy-row` 核对复制的制表符文本；真实 Ctrl+C（含搜索框有焦点时不触发）；真实鼠标与键盘走完“表头右键 → 导出为 CSV… → 敏感列提示（Esc 取消 / 继续导出）→ 系统保存对话框（Esc 取消 / 粘贴路径回车保存）”以及性能页“导出当前快照…”。

以下只留下自动测试覆盖不到的观感与第三方程序行为（4 级，等回到电脑前）：

- [ ] 1. Excel 打开中文不乱码、列与界面一致（4 级）
  - 操作：进程页显示几列详细信息（如“用户名”“命令行”“线程”），右键任意进程 → “导出为 CSV…” → 继续导出 → 保存；用 Excel 双击打开。再在性能页点“导出当前快照…”保存并用 Excel 打开。
  - 预期：中文表头、进程名、用户名不乱码；列顺序与进程页一致（名称、PID、CPU、内存、磁盘、已选列）；CPU 显示为百分比、内存为“x.x MB”文本；性能快照是长表（类型/资源/实例/指标/时间/距今（秒）/数值/单位），“数值”列是数字。
- [ ] 2. 含逗号、引号的命令行在 Excel 中正确显示（4 级）
  - 操作：用 `powershell -NoProfile -Command "Start-Sleep 600 # a,b \"q\" c"` 启动一个进程，显示“命令行”列后导出，用 Excel 打开找到该行。
  - 预期：命令行完整落在同一个单元格里（不被逗号拆成多列），其中的引号正常显示。
- [ ] 3. 分组与树形视图导出的层级（4 级）
  - 操作：分别切到“树形”“分组”视图（把几个应用折叠起来）导出，用 Excel 打开。
  - 预期：树形多一列“层级”；分组多“分组”（应用/后台进程）和“层级”两列，应用在前、后台进程在后；折叠的应用的子进程也在导出里（层级 ≥ 1），应用行的 CPU/内存是合计，与界面一致。
- [ ] 4. 敏感列提示的观感（4 级）
  - 操作：显示“命令行”“映像路径”“用户名”中任意几列，右键进程或右键表头 → “导出为 CSV…”；分别在浅色、深色主题和 760×480 的最小窗口下看一遍。
  - 预期：弹出与“结束进程树”确认框同风格的对话框，标题“导出包含敏感信息的列？”，正文列出所含列名，按钮“取消”“继续导出”；文字不被裁切；点“取消”或按 Esc 不弹保存对话框；不含这三类列时不出现该提示、直接弹保存对话框。
- [ ] 5. 保存对话框的实际体验（4 级）
  - 操作：导出时观察系统保存对话框；把文件保存到已存在的同名文件上；保存到没有写权限的目录（如 `C:\Windows`）；保存对话框打开期间拖动、最小化主窗口。
  - 预期：默认文件名形如 `进程列表-2026-10-30 15-04-05.csv`（性能页为 `性能快照-…`），文件类型 CSV；同名文件时系统询问是否覆盖；无权限时状态栏红字显示“操作失败：导出 CSV（无法写入 …：…）”且程序不崩溃；取消时没有任何提示；保存对话框打开时主窗口可正常重绘、不卡死。
- [ ] 6. 复制所选行（4 级）
  - 操作：选中一行按 Ctrl+C（或右键 → “复制所选行”），粘贴到记事本和 Excel；在搜索框里选中文字按 Ctrl+C。
  - 预期：记事本里是一行制表符分隔的文字，列与导出一致（不含表头）；粘贴到 Excel 自动分成多列；状态栏显示“已复制 {进程名} 的行”；搜索框里的 Ctrl+C 只复制所选文字。
- [ ] 7. 入口位置与按钮观感（4 级）
  - 操作：进程页右键进程行与右键表头；性能页左栏底部。
  - 预期：行菜单末尾（“在线搜索进程名”之后的分隔线下）有“复制所选行”“导出为 CSV…”；表头菜单末尾（“恢复默认列”之后）有“导出为 CSV…”；性能页左栏底部有通栏的“导出当前快照…”按钮，与卡片间距协调，窗口缩到最小时不被裁切；顶栏没有新增控件。
