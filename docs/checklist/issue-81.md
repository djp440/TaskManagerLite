## 常驻开销

`pwsh scripts/measure-idle.ps1 -Seconds 30`（进程页、不悬停），本任务的构建：CPU 占整机 0.18% / 0.18%（两次，656 ms CPU 时间 / 30 秒），工作集 46.9 / 46.8 MB，私有提交 27.8 / 27.7 MB；同一台机器上、本任务之前的旧构建（#86）：0.17%，工作集 48.5 MB，私有提交 27.3 MB。差别在噪声内（采样热路径只多一次 O(进程数) 的单次扫描和每曲线每采样一次哈希查找；不悬停时界面没有任何额外工作）。测量时本机并不空闲，数字只作同机对照。

## 范围与已知取舍（验收时对照）

- 有悬停的曲线：性能页详情大图——CPU（整体利用率视图）、内存、磁盘（每块物理磁盘各自）、网络、GPU 利用率。**不支持**：CPU“逻辑处理器”小图（每个格子太小，这个视图下悬停整体禁用）、GPU 专用 / 共享显存两条曲线、左栏缩略图、迷你模式。
- 进程名只有 CPU、磁盘曲线有。**网络没有进程级数据**（项目只采网卡级吞吐，不做按进程网络采集——需要 ETW 内核网络会话 / 提权，不在本任务范围），网络曲线只显示数值与时间；内存、GPU 没有“最高进程”的概念。
- 磁盘的进程是整机口径：进程磁盘速率不区分物理磁盘，多块磁盘时卡片写“全部磁盘读写最高：…”，不要把它理解成“这块盘上最忙的进程”；磁盘速率的来源随设置（未开 ETW 是近似值）。
- 峰值进程只在采样时记录，所以：只采系统指标的采样（窗口不可见且开了后台继续采样）、进程名表装不下被淘汰的旧进程（上限 512 个，淘汰最久没当过峰值的）、重启程序之前的历史，这些点只显示数值与时间，不显示进程。
- 长窗口的点是聚合桶：显示“峰值”（曲线按它画）与“均值”，时间写“约 N 秒前（每点 K 秒）”；峰值进程是桶内取得最大值那一次采样的进程。
- 鼠标落在断档（暂停、窗口不可见）里或曲线开始之前显示“该时刻没有数据”、不画圆点；断档边缘一个采样间隔（长窗口一个桶宽）内仍算边缘的点，避免 1 像素的偏差让提示忽有忽无。
- 提示卡片固定 288 逻辑像素宽，进程名过长在卡片里省略；日志只记数值，鼠标进入时一行（含 PID，不含进程名）、离开时一行。

## 人工验收（等回到电脑前）

- [ ] 1. 真实鼠标悬停跟手观感（4 级）
  - 操作：性能页依次选 CPU、内存、磁盘、网络、GPU，鼠标在曲线上左右、上下移动，再切 60 秒 / 5 分钟 / 10 分钟 / 1 小时窗口各试一次。
  - 预期：竖直引导线紧跟鼠标 x；卡片内容随位置变化，圆点落在曲线上、高度与卡片数值一致；移出曲线区立即消失；鼠标不动时，每秒采样后提示跟着曲线向左滚动更新，没有闪烁；逻辑处理器视图下没有提示。
  - 用户反馈：

- [ ] 2. 卡片位置与遮挡（4 级）
  - 操作：鼠标移到曲线最右、最左、最上、最下，再把窗口缩到最小宽度 / 高度重试。
  - 预期：靠右时卡片翻到引导线左侧，右缘一条窄带里的最新数据不被压住；靠上 / 下卡片夹紧在曲线区内、不越出曲线框；窗口很窄 / 很矮时卡片仍在曲线区内（可能盖住大部分曲线，但不越界）。
  - 用户反馈：

- [ ] 3. CPU 尖峰处的进程（4 级）
  - 操作：运行任意压力程序（如死循环脚本）数秒后结束，悬停尖峰处；再选 5 分钟 / 10 分钟窗口对尖峰悬停。
  - 预期：卡片出现该进程名与 PID；长窗口显示该桶峰值 / 均值与“约 N 秒前（每点 K 秒）”，进程仍是尖峰那次采样的进程。
  - 用户反馈：

- [ ] 4. 缺口（4 级）
  - 操作：采样间隔改成“暂停”等一会再改回 1 秒，在空白处与空白边缘悬停（60 秒与 5 分钟窗口）。
  - 预期：空白里显示“该时刻没有数据”、没有圆点；两侧有曲线的位置正常显示数值。
  - 用户反馈：

- [ ] 5. 浅色主题与深浅对比（4 级）

  - 预期：卡片底色与边框、文字、引导线、圆点在浅色下清晰可辨，与曲线色不混淆。
