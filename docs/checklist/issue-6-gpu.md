# issue #6 GPU 性能页验收

- [ ] 1. 硬件与名称：进入性能页，本机应只有 NVIDIA GeForce RTX 5070 Ti 与 AMD Radeon(TM) Graphics 两张 GPU 卡片，卡片与详情页显示型号，不出现软件或重复适配器。
- [ ] 2. 显存容量：点击两张卡片。预期专用/共享显存均显示“已用 / 总量”，曲线以对应总量为纵轴上限；两条显存曲线与利用率曲线都有外框。RTX 5070 Ti 专用显存约 16 GB，核显专用显存约 0.5 GB；共享容量约 23.6 GB。
- [ ] 3. 游戏或视频负载对照：运行游戏或播放硬件解码视频，同时查看原生任务管理器相同型号的 GPU。预期利用率和专用/共享显存基本一致；采样时刻不同允许波动。卡片编号按 DXGI 枚举顺序生成，不保证与原生任务管理器一致。
- [ ] 4. 暂停与恢复：暂停采样数秒后恢复，或最小化后恢复。预期曲线在暂停区间断开，重新采样后继续更新。
