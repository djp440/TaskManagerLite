- [x] **10. 开机启动（#16）**

  - 预期：开启托盘时登录后只出现托盘图标、不弹窗口；关闭托盘时登录后窗口最小化在任务栏；在系统里禁用后，设置页开关为关闭并提示“已在 Windows 设置的‘启动应用’中被禁用”，重新打开开关即恢复。
  - 反馈：通过（2026-10-28）

- [x] **11. 替换系统任务管理器（#16，需要 UAC）**
  - 操作：把 exe 放到 Program Files 下的目录运行；设置页打开“替换系统任务管理器”，在 UAC 中先点“否”，再打开一次点“是”；按 Ctrl+Shift+Esc；最后关闭开关。
  - 预期：等待授权期间开关不可点、显示“正在等待管理员授权…”；取消后开关回到关闭并提示已取消；授权后开关保持开启，Ctrl+Shift+Esc 打开本程序；关闭后恢复系统任务管理器。放在可被普通用户写入的目录（如构建目录）时会拒绝登记并以红字说明原因。
  - 反馈：通过（2026-10-28）

- [x] **12. 接管任务管理器的补充项（#7，需要 UAC）**
  - 操作：（第 11 项完成后）①开启接管后连按两次 Ctrl+Shift+Esc，再用任务栏右键 →“任务管理器”；②把 exe 放到 `C:\` 根下新建的目录，运行 `TaskManagerLite.exe --register-taskmgr`；③登记后把 exe 移到另一个目录运行，打开设置页；④按 Ctrl+Alt+Del 选“任务管理器”。
  - 预期：①打开的是本程序（不自动提权），已打开时只把窗口带到前台，日志里有“由 Taskmgr.exe 的 IFEO 重定向启动”；②不弹 UAC，退出码 5；③设置页提示“登记的程序已不存在…，开启后改为本程序”，重新打开开关即可改到新位置；④观察是否同样被重定向、安全软件是否报警（仅记录现象）。撤销后 Ctrl+Shift+Esc 立即恢复系统任务管理器；手动还原的方法是在管理员命令提示符执行 `reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\Taskmgr.exe" /v Debugger /f`。
  - 反馈：通过（2026-10-28）

- [x] **13. 精确磁盘统计（#5，需要管理员终端）**
  - 操作：①管理员终端运行 `pwsh scripts/test-etw-disk.ps1`；②以管理员身份启动，在设置页打开“精确磁盘统计”，同时打开资源监视器的“磁盘”页，拷贝几 GB 的大文件；③开启后在管理员终端运行 `pwsh scripts/measure-idle.ps1`，与关闭时对比；④开启状态下用系统任务管理器结束本程序，执行 `logman query -ets`，再启动本程序。
  - 预期：①全部通过；②列头为“磁盘”（不是“磁盘 ≈”），设置页显示 ETW 已生效，拷贝进程与 System 的速率量级与资源监视器接近；③CPU 增量在噪声内（不超过 +0.1 个百分点）；④能看到残留的 `TaskManagerLite-DiskIo-*` 会话，再次启动并开启后被清理。全部通过后再考虑把默认值改为开启。
  - 反馈：通过（2026-10-28）
