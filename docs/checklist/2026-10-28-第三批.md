## 待验收

- [ ] **1. 列选择菜单的勾选状态（#17）**
  - 操作：进程页任意列标题上右键，勾选“用户名”；再右键，确认“用户名”带勾；点“恢复默认列”；再右键。
  - 预期：每次勾选后菜单状态与列是否显示一致；恢复默认列后“用户名”不再带勾，再点它会重新显示该列（而不是反过来隐藏）。
  - 反馈：

- [ ] **2. 横向滚动（#17）**
  - 操作：显示 6 列以上详细信息列，让窗口放不下；分别用鼠标水平滚轮、Shift+滚轮、触控板双指横滑、底部滚动条横向滚动。
  - 预期：表头与行一起滚动且始终对齐；滚动流畅，没有闪烁或文字错位。
  - 反馈：

- [ ] **3. 拖动详细信息列宽（#17）**
  - 操作：横向滚到中间位置，用鼠标拖动某个详细信息列标题右侧的分隔线，左右来回拖；双击分隔线。
  - 预期：分隔线跟手，被拖列右侧的内容在屏幕上不动；双击恢复该列默认宽度；重启后列宽保持。
  - 反馈：

- [ ] **4. 迷你模式拖动与置顶（#19）**
  - 操作：性能页点工具栏的迷你模式按钮（或 Ctrl+M）；按住卡片或卡片间空隙拖到屏幕各处，包括拖到副屏、拖到屏幕边缘；再打开其他窗口盖住它。
  - 预期：拖动跟手，松开后窗口停在原处，不会松手后还在跟着鼠标走；默认浮在其他窗口之上；右键菜单取消“窗口置顶”后可以被其他窗口盖住。
  - 反馈：

- [ ] **5. 迷你模式右键菜单与不透明度（#19）**
  - 操作：迷你窗口上右键，依次选 90%、70%、60%、100% 不透明度；再右键看勾选位置；退出后重新打开程序。
  - 预期：透明度立即变化，文字仍清晰可读；菜单里只有当前档位带勾；退出时处于迷你模式的，重开后直接是迷你窗口，位置、置顶、不透明度都和退出前一样。
  - 反馈：

- [ ] **6. 迷你模式返回完整模式（#19）**
  - 操作：在进程页选中某个进程并滚动到中间，切到性能页选中“磁盘”，进入迷你模式；分别用双击、Esc、Ctrl+M、右键“返回完整模式”回到完整窗口。
  - 预期：完整窗口出现在原位置、原大小，并获得焦点；性能页仍选中“磁盘”，大图立即有曲线；切回进程页时选中项和滚动位置不变。
  - 反馈：

- [ ] **7. 迷你模式与托盘（#19 × #8）**
  - 操作：设置文件开启 `close_to_tray`，进入迷你模式后按 Alt+F4；点托盘图标；再右键托盘选“退出”。
  - 预期：Alt+F4 后迷你窗口隐藏到托盘；点托盘图标后迷你窗口重新出现（不是完整窗口）；托盘退出后下次启动仍是迷你模式。
  - 反馈：

- [ ] **8. 设置页的外观与入口（#16）**
  - 操作：点顶栏最右侧的齿轮进入设置页；上下滚动；把窗口拖到最窄（760）再拉宽；再点一次齿轮。
  - 预期：分组卡片、开关、说明文字排版整齐，深浅色下都清晰；最窄时文字换行、不被截断，工具栏不被挤出窗口（进程页最窄时置顶按钮会收起，设置页里仍可切换置顶）；再点齿轮回到进入前的页面。默认窗口宽度由 1040 调为 1080，以便进程页在默认宽度下完整显示“以管理员身份重启”与品牌字样，请确认这个默认大小合适。
  - 反馈：

- [ ] **9. 主题切换（#16）**
  - 操作：设置页依次选“浅色”“深色”“跟随系统”；选“跟随系统”后到 Windows 设置里切换深浅色模式；进入迷你模式看迷你窗口；重启程序。
  - 预期：切换立即生效，完整窗口与迷你窗口一致；跟随系统时随 Windows 切换而变化；重启后保持上次的选择。
  - 反馈：

- [ ] **10. 开机启动（#16）**
  - 操作：设置页打开“开机时启动”；注销或重启 Windows 再登录。分别在“关闭时最小化到托盘”开启和关闭时各试一次；再到 Windows 设置 → 应用 → 启动 里关掉本程序，回到设置页看状态。
  - 预期：开启托盘时登录后只出现托盘图标、不弹窗口；关闭托盘时登录后窗口最小化在任务栏；在系统里禁用后，设置页开关为关闭并提示“已在 Windows 设置的‘启动应用’中被禁用”，重新打开开关即恢复。
  - 反馈：

- [ ] **11. 替换系统任务管理器（#16，需要 UAC）**
  - 操作：把 exe 放到 Program Files 下的目录运行；设置页打开“替换系统任务管理器”，在 UAC 中先点“否”，再打开一次点“是”；按 Ctrl+Shift+Esc；最后关闭开关。
  - 预期：等待授权期间开关不可点、显示“正在等待管理员授权…”；取消后开关回到关闭并提示已取消；授权后开关保持开启，Ctrl+Shift+Esc 打开本程序；关闭后恢复系统任务管理器。放在可被普通用户写入的目录（如构建目录）时会拒绝登记并以红字说明原因。
